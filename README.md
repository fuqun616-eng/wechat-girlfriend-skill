# 💕 微信虚拟女友 AI 技能

> 让你的 AI 角色卡变成一个会主动记忆、有情绪变化的微信女友。

基于 **Operit 平台** 的角色卡驱动微信自动回复系统，内置记忆管理、情绪感知、亲密度系统和模式切换。

---

## 功能特性

- 角色卡驱动 - 严格遵循角色人设，自动适配语气风格
- 记忆系统 - 分层记忆（永久/长期/短期/情绪），自动消逝与整理
- 亲密度系统 - 动态评分（0-100），影响称呼和语气亲密度
- 持续监控 - 60秒长轮询，自动回复，永不掉线
- 调试模式 - 支持 at[...] 标记切换技术助手模式
- 安全约束 - 内置内容安全边界，保持角色沉浸感
- 定时记忆整理 - 每日凌晨自动清理过期记忆

## 快速开始

1. 安装所需包
2. 创建角色卡
3. 运行技能 -> 扫码登录微信
4. 开始聊天！
